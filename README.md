# EduKit — المحفظة التربوية
**إعداد وإشراف: RACHID EL MOURABIT** — منصة اختبارات تفاعلية للتحضير لمباراة التعليم بالمغرب.

> منصة تعليمية مستقلة، وليست منصة رسمية تابعة لوزارة التربية الوطنية. جميع الأسئلة المضمّنة **تدريبية** من إعداد المنصة، وليست مأخوذة من مباريات رسمية سابقة.

## ما الذي يعمل وما الذي يحتاج خدمة خارجية

| الميزة | بدون خادم (استضافة ثابتة) | مع Netlify (موصى به) |
|---|---|---|
| الصفحة الرئيسية، المجالات، الاختبارات، التصحيح، النتائج، الطباعة، المشاركة، عربي/فرنسي | ✅ | ✅ |
| اختبار علوم التربية الأول (15 سؤالاً) + اختبارات عشوائية متنوعة | ✅ | ✅ |
| لوحة تحكم الأستاذ (كلمة مرور محمية على الخادم) | ❌ | ✅ |
| إضافة/تعديل/حذف الأسئلة والمجالات والاختبارات من اللوحة | ❌ | ✅ |
| حفظ نتائج المترشحين مجهولة المصدر + إحصائيات + تصدير CSV | ❌ | ✅ |

بدون خادم تعمل المنصة كاملة للمترشح، لكن النتائج تبقى في متصفحه فقط، وتظهر له رسالة بذلك.
لوحة التحكم تحتاج دالة خادمية، لذلك لا تعمل على GitHub Pages.

## النشر على Netlify (خطوات)

1. أنشئ حساباً مجانياً على netlify.com.
2. ارفع المشروع إلى مستودع GitHub (أو استعمل Netlify CLI).
3. في Netlify: **Add new site ← Import an existing project** واختر المستودع. الإعدادات تُقرأ تلقائياً من `netlify.toml` (النشر من `public`، والدوال من `netlify/functions`).
4. قبل أول نشر (أو بعده ثم أعد النشر): **Site configuration ← Environment variables** وأضف:
   - `ADMIN_PASSWORD` = كلمة مرور قوية من **10 أحرف على الأقل** (لا توجد كلمة مرور افتراضية؛ بدونها تُرفض لوحة التحكم).
5. بعد النشر تحصل على رابط مثل `https://اسم-موقعك.netlify.app`: هذا هو الرابط الذي تشاركه مع المترشحين. يمكنك تغيير الاسم من **Domain management**.
6. لوحة التحكم: `الرابط/admin.html`.

بدون Git: ثبّت `npm i -g netlify-cli` ثم نفّذ داخل المجلد `npm install` ثم `netlify deploy --prod`.

## الحماية
- كلمة المرور لا توجد في أي ملف JavaScript؛ تُقرأ من متغير بيئة على الخادم فقط.
- الدخول يُنتج رمزاً موقّعاً (HMAC) صالحاً 8 ساعات، وكل مسارات `/api/admin/*` تتحقق منه.
- قفل 15 دقيقة بعد 5 محاولات دخول خاطئة (على مستوى نسخة الدالة، فهو حماية أساسية وليس بديلاً عن كلمة مرور قوية).
- المحتوى المرسل من اللوحة يُتحقق منه على الخادم، والنتائج المخزنة مجهولة (بدون اسم أو عنوان IP) وبحدّ معدل.
- غيّر `ADMIN_PASSWORD` لإبطال كل الجلسات القديمة.

## بنية المشروع
```
public/            الواجهة الثابتة
  index.html, admin.html
  js/bank.js       بنك الأسئلة والمجالات والاختبار الثابت (البيانات)
  js/engine.js     منطق اختيار الأسئلة والتصحيح (بلا DOM)
  js/app.js        واجهة المترشح      js/admin.js   واجهة اللوحة
  js/i18n.js       الترجمة عربي/فرنسي
netlify/functions/ api.mjs (دالة Netlify) + lib/core.mjs (منطق الخادم)
tests/run.mjs      31 اختباراً آلياً:  npm test
tests/devserver.mjs خادم محلي للتجربة (ADMIN_PASSWORD=... node tests/devserver.mjs)
```

## كيف تعمل الاختبارات
- 15 سؤالاً دائماً: 8 QCM، 2 صح/خطأ، 2 وضعيات مهنية، 1 إكمال فراغ، 1 مطابقة، 1 تطبيقي، مرتبة من السهل إلى الصعب، مع تفضيل أسئلة لم تظهر للمترشح سابقاً.
- نقطة لكل جواب صحيح بلا خصم، والمطابقة تُحتسب إذا صحّت كل أزواجها. التسليم مرة واحدة لكل محاولة.
- الأنماط: تدريب (تصحيح فوري)، امتحان (مؤقت اختياري)، شامل (كل المجالات الجاهزة).
- المجال يُفتح للاختبار فقط عندما يبلغ **15 سؤالاً**. حالياً الجاهز: علوم التربية (28 سؤالاً) و«الاختبار الشامل». أما ديداكتيك المواد (5) والتشريع المدرسي (0) والمستجدات (4) والمعارف (6) فتظهر «قيد الإعداد» إلى أن تضيف أسئلتها من لوحة التحكم.

## ما يجب أن تراجعه قبل النشر
- راجع علمياً أسئلة علوم التربية والمستجدات، فهي من إعداد Claude، ومصادرها مراجع عامة. لا تُنسب أي مصدر رسمي إلا بعد التحقق من النص.
- أسئلة التشريع المدرسي **لم تُكتب عمداً** لأنها تتطلب نصوصاً رسمية موثقة (النظام الأساسي، المراسيم...) لتفادي اختلاق مقتضيات. أضفها من اللوحة مع ذكر المصدر.
- يمكن وسم سؤال «مأخوذ من مباراة رسمية» فقط مع إدخال مصدر؛ وإلا يرفضه الخادم.
- الخط Cairo يُحمَّل من Google Fonts؛ إن تعذّر يُستعمل خط النظام.

## إضافة محتوى بالشيفرة
أضف الأسئلة إلى `public/js/bank.js` بالصيغة الموجودة، أو استعمل اللوحة (لا تحتاج تعديل الشيفرة).
